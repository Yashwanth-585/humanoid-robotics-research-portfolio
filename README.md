# Humanoid Robotics Research Portfolio

A documentation-only portfolio of selected humanoid robotics and autonomous systems work.

This repository summarises project objectives, technical approaches, individual contributions, validation, observed limitations, and future directions. It intentionally contains no source code, model weights, deployment files, private datasets, credentials, or internal configuration files.

## Research projects

| Project | Focus | Status |
|---|---|---|
| [Reinforcement-learning stair climbing](projects/stair-climbing/README.md) | Blind locomotion policy development and simulation-to-real evaluation on Unitree G1 | Physical stair-climbing demonstration completed; limitations documented |
| [G1 bottle pickup and handover](projects/bottle-pickup-handover/README.md) | RGB-D bottle perception, 3D localisation, right-arm planning, dexterous grasping and tug-triggered handover | Integrated physical pick-and-lift demonstrated; handover reported working; scope and limitations documented |
| Autonomous navigation and mapping | LiDAR-based mapping and localisation on Unitree G1 | Documentation in progress |

## Attribution and disclosure

The projects described here were carried out in a collaborative research environment with mentor guidance and, where applicable, assistance from other team members. Individual contributions are identified separately from team-level outcomes.

Some project development used AI-assisted coding and existing open-source or vendor software. The portfolio distinguishes personal engineering direction, integration, experimentation and validation from work provided by AI tools, libraries and SDKs.

Descriptions are intentionally high-level. No proprietary implementation details or restricted artefacts are included. Any future media or additional technical detail should be added only after confirming that it is approved for public release.

## Repository structure

- `projects/`: individual project case studies
- `assets/`: approved, publication-safe media only

This repository is a personal technical portfolio. It is not an official publication or endorsement by any institution, laboratory, or robot manufacturer. Product and framework names are used only to identify technologies involved in the work.
