# Approved media only

Place only images, videos, diagrams, or other media that have been explicitly approved for public sharing.

Before adding media, check for:
- People, badges, access cards, screens, or identifying information.
- Robot serial numbers, network details, workspace layouts, or proprietary equipment.
- Internal dashboards, software windows, file paths, or configuration details.
- Third-party material or content requiring permission.

When in doubt, omit the media.
